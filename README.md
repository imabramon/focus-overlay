# Focus Overlay

Прозрачный оверлей поверх игр с вкладками в Markdown. Windows 10 / 11, .NET 8, WPF.

## Скачать

Готовый `FocusOverlay.exe` лежит в [релизах](https://github.com/imabramon/focus-overlay/releases/latest). Установка не нужна, .NET ставить не надо: скачайте файл и запустите.

## Сборка и запуск

```
dotnet run --project src/FocusOverlay
```

Один exe без установки .NET:

```
dotnet publish src/FocusOverlay -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish
```

## Использование

- Иконка в трее: двойной клик открывает редактор, правый клик открывает меню (настройки, пресеты, импорт и экспорт, выход).
- Окно «Настройки» (из трея или кнопкой в редакторе) с вкладками «Оверлей» (угол экрана, отступы, размер, масштаб, шрифт, фон, цвета с палитрой), «Полоса вкладок» (показ, отдельное положение, масштаб, шрифт, фон, цвета) и «Горячие клавиши». Настройки можно импортировать и экспортировать в `.json` (формат `focus-overlay-settings`) и сбросить по умолчанию.
- Резервная копия всего — настроек и всех пресетов с картинками — делается кнопками «Экспорт всего…» / «Импорт всего…» в «Настройках» или в меню трея. Файл `.foverlay-backup` — это zip. При загрузке можно заменить текущие пресеты или добавить к ним.
- Оверлей не перехватывает мышь и не забирает фокус у игры.
- Игра должна работать в режиме **«Оконный без рамки» / Borderless**. В эксклюзивном полноэкранном режиме оверлеи не видны.
- Если игра запущена от администратора, оверлей тоже нужно запускать от администратора, иначе горячие клавиши не сработают.

### Горячие клавиши по умолчанию

Клавиши можно переназначить в окне «Настройки».

| Действие | Клавиши |
|---|---|
| Показать / скрыть | `Ctrl+Alt+O` |
| Предыдущая / следующая вкладка | `Ctrl+Alt+←` / `Ctrl+Alt+→` |
| Прокрутка вверх / вниз | `Ctrl+Alt+↑` / `Ctrl+Alt+↓` |
| Масштаб + / − | `Ctrl+Alt+=` / `Ctrl+Alt+-` |
| Следующий пресет | `Ctrl+Alt+P` |
| Предыдущий пресет | не назначено, можно задать в настройках |
| Оверлей вверх / вниз | `Ctrl+Alt+Z` / `Ctrl+Alt+B` |
| Оверлей влево / по центру / вправо | `Ctrl+Alt+X` / `Ctrl+Alt+C` / `Ctrl+Alt+V` |
| Сбросить положение и масштаб | `Ctrl+Alt+R` |

Масштаб и положение, изменённые клавишами, действуют на все вкладки и пресеты и сохраняются после перезапуска. Вернуть оверлей к настройкам приложения, пресета и вкладки можно сочетанием `Ctrl+Alt+R` или пунктом «Сбросить положение и масштаб» в меню трея.

На некоторых ноутбуках с графикой Intel `Ctrl+Alt+стрелки` поворачивают экран. Если так происходит, отключите эти сочетания в панели управления графикой Intel или переназначьте клавиши в «Настройках».

## Формат пресета (`.foverlay` — это zip)

```
manifest.json
pages/01.md
pages/02.md
assets/icon.png
```

```json
{
  "format": "focus-overlay-preset",
  "version": 1,
  "name": "Мой билд",
  "pages": [{ "title": "Билд", "file": "pages/01.md" }]
}
```

Zip без `manifest.json` тоже импортируется: каждый `.md` файл становится вкладкой.

## Импорт папки с `.md`

Кнопка «Импорт ▾» → «Папка с .md…» в редакторе или пункт «Импорт папки с .md…» в трее:

- каждый `.md` файл, включая файлы в подпапках, становится вкладкой; название вкладки берётся из имени файла, порядок как в Проводнике (`2.md` идёт раньше `10.md`);
- имя пресета берётся из имени папки;
- картинки из папки копируются в ассеты пресета, относительные ссылки `![](img/a.png)` продолжают работать;
- скрытые папки (`.obsidian`, `.git` и т.п.) пропускаются.

Данные приложения: `%AppData%\FocusOverlay` (`state.json` и `presets/<id>/assets`).
