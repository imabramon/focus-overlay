# Разметка вкладок

Вкладки пишутся в Markdown. Всё ниже показывается на оверлее. В обычных просмотрщиках Markdown (GitHub, Obsidian, VS Code) такие файлы тоже читаются нормально, только без дополнений Focus Overlay.

## Текст

| Разметка | Результат |
|---|---|
| `# Заголовок` … `###### Заголовок` | заголовки 1–6 уровня; 1 и 2 уровни выделяются цветом акцента |
| `**жирный**` | **жирный** |
| `*курсив*` | *курсив* |
| `~~зачёркнутый~~` | ~~зачёркнутый~~ |
| `==выделение==` | текст с фоном цвета акцента |
| `++подчёркнутый++` | подчёркнутый текст |
| `` `код` `` | `код` моноширинным шрифтом |
| `[текст](https://…)` | ссылка (на оверлее не кликается) |
| `https://example.com` | ссылка без разметки |

Каждый перенос строки в тексте сохраняется, ставить два пробела в конце строки не нужно.

## Списки и задачи

```markdown
- маркированный список
  - вложенный пункт

1. нумерованный список
2. второй пункт

- [x] выполненная задача
- [ ] невыполненная задача
```

## Цитаты, код, разделитель

````markdown
> Цитата: рамка цвета акцента, курсив

```
Блок кода
```

---
````

`---` рисует горизонтальную линию.

## Таблицы

```markdown
| Слот | Аспект | Статы |
|:---|:---:|---:|
| Шлем | — | КДР |
```

Двоеточия в строке-разделителе задают выравнивание: `:---` влево, `:---:` по центру, `---:` вправо.

### Параметры таблицы

Строка `{...}` **через пустую строку над таблицей** задаёт её параметры:

```markdown
{widths="120,1*,2*" borders=rows}

| Слот | Аспект | Статы |
|---|---|---|
| Шлем | — | КДР |
```

На оверлее эта строка не показывается. В других просмотрщиках она видна обычным текстом, а таблица отображается как обычно.

| Параметр | Значения |
|---|---|
| `widths` | ширины колонок через запятую: `120` или `120px` — фиксированная в пикселях; `2*` — доля оставшегося места; `30%` — процент; `*` — то же, что `1*`. Колонки без указанной ширины получают среднюю долю указанных. |
| `borders` | `all` — все границы (по умолчанию); `none` — без границ; `rows` — только линии между строками; `outer` — только внешняя рамка |

Значения с запятыми, пробелами или `*` берите в кавычки: `widths="1*,2*"`.

## Изображения

```markdown
![подпись](icon.png)
```

Откуда берётся файл:

- имя файла или относительный путь (`icon.png`, `img/icon.png`) — из папки ассетов пресета;
- абсолютный путь (`C:/images/icon.png`) или ссылка `https://…`.

Добавить файл в ассеты пресета можно в редакторе: кнопкой «Изображение…», через Ctrl+V из буфера обмена или перетаскиванием файла в поле текста. Ссылка на него вставится сама.

### Размер

Размер задаётся в подписи после `|`:

| Разметка | Размер |
|---|---|
| `![иконка\|32](icon.png)` | ширина 32, высота по пропорциям |
| `![иконка\|32x24](icon.png)` | вписать в 32 × 24 |
| `![иконка\|x24](icon.png)` | высота 24, ширина по пропорциям |
| `![иконка](icon.png)` | исходный размер, но не шире оверлея |

Внутри таблицы `|` нужно экранировать: `![иконка\|32](icon.png)`. Иначе Markdown посчитает его границей ячейки.

Картинки стоят в строке вместе с текстом, поэтому их удобно ставить как иконки рядом с названиями: `![skill|24](skill.png) Название`.

## Настройки вкладки

Блок кода с языком `focus-overlay` меняет вид оверлея, пока открыта эта вкладка. На оверлее сам блок не показывается.

````markdown
```focus-overlay
corner: bottom-right
width: 520
height: 700
scale: 1.2
font-size: 15
opacity: 50%
text-color: #FFFFFF
accent-color: #3498DB
```
````

Блок меняет только окно с содержимым вкладки. Полоса с названиями вкладок от этого блока не зависит: у неё свои настройки (окно «Настройки» → «Полоса вкладок»), поэтому при переключении вкладок она не прыгает. Если полоса прикреплена к оверлею, а вкладка не меняет `corner`, `offset-x` и `offset-y`, содержимое стоит вплотную к полосе вкладок. Если меняет, содержимое переезжает в указанное место, а полоса остаётся на своём.

Неуказанные параметры берутся из общих настроек. Блок можно поставить в любом месте вкладки. Строки `# …` и `// …` считаются комментариями. Вместо `:` можно писать `=`.

| Параметр | Значение |
|---|---|
| `corner` | угол экрана: `top-left`, `top-right`, `bottom-left`, `bottom-right` |
| `offset-x`, `offset-y` | отступ от края экрана в пикселях |
| `width`, `height` | размер оверлея в пикселях (минимум 150 × 100) |
| `scale` | **множитель** к общему масштабу: `1.2` — на 20 % крупнее. Горячие клавиши масштаба продолжают работать |
| `font-size` | размер шрифта (6–48) |
| `opacity` | прозрачность фона: `0.5` или `50%` |
| `text-color`, `accent-color` | цвет: `#RRGGBB`, `#AARRGGBB` или имя (`White`, `Gold`) |

Названия параметров не зависят от регистра, дефисов и подчёркиваний: `font-size`, `fontSize` и `font_size` значат одно и то же.
