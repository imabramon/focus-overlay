# Разметка вкладок

Вкладки пишутся в Markdown. Всё ниже показывается на оверлее. В обычных просмотрщиках Markdown (GitHub, Obsidian, VS Code) такие файлы тоже читаются нормально, только без дополнений Focus Overlay.

## Текст

| Разметка | Результат |
|---|---|
| `# Заголовок` … `###### Заголовок` | заголовки 1–6 уровня; 1 и 2 уровни выделяются цветом акцента |
| `**жирный**` | **жирный** |
| `*курсив*` | *курсив* |
| `~~зачёркнутый~~` | ~~зачёркнутый~~ |
| `==выделение==` | текст с фоном цвета акцента |
| `++подчёркнутый++` | подчёркнутый текст |
| `` `код` `` | `код` моноширинным шрифтом |
| `[текст](https://…)` | ссылка (на оверлее не кликается) |
| `https://example.com` | ссылка без разметки |

Каждый перенос строки в тексте сохраняется, ставить два пробела в конце строки не нужно.

## Списки и задачи

```markdown
- маркированный список
  - вложенный пункт

1. нумерованный список
2. второй пункт

- [x] выполненная задача
- [ ] невыполненная задача
```

## Цитаты, код, разделитель

````markdown
> Цитата: рамка цвета акцента, курсив

```
Блок кода
```

---
````

`---` рисует горизонтальную линию.

## Таблицы

```markdown
| Слот | Аспект | Статы |
|:---|:---:|---:|
| Шлем | — | КДР |
```

Двоеточия в строке-разделителе задают выравнивание: `:---` влево, `:---:` по центру, `---:` вправо.

### Параметры таблицы

Строка `{...}` **через пустую строку над таблицей** задаёт её параметры:

```markdown
{widths="120,1*,2*" borders=rows}

| Слот | Аспект | Статы |
|---|---|---|
| Шлем | — | КДР |
```

На оверлее эта строка не показывается. В других просмотрщиках она видна обычным текстом, а таблица отображается как обычно.

| Параметр | Значения |
|---|---|
| `widths` | ширины колонок через запятую: `120` или `120px` — фиксированная в пикселях; `2*` — доля оставшегося места; `30%` — процент; `*` — то же, что `1*`. Колонки без указанной ширины получают среднюю долю указанных. |
| `borders` | `all` — все границы (по умолчанию); `none` — без границ; `rows` — только линии между строками; `outer` — только внешняя рамка |

Значения с запятыми, пробелами или `*` берите в кавычки: `widths="1*,2*"`.

## Изображения

```markdown
![подпись](icon.png)
![[icon.png]]
```

Второй вариант — синтаксис Obsidian, его удобно использовать, если файлы пишутся в Obsidian. Размер в нём указать нельзя: картинка всегда в исходном размере, но не шире оверлея. Всё после `|` игнорируется. Если нужен размер, используйте `![подпись|32](путь)`.

Откуда берётся файл:

- имя файла или относительный путь (`icon.png`, `img/icon.png`) — из папки ассетов пресета. Если указано только имя файла без папок (`icon.png`) и в корне его нет, он ищется по имени во всех подпапках ассетов (как в Obsidian). Если указан путь с папками, файл берётся только по этому пути;
- абсолютный путь (`C:/images/icon.png`) или ссылка `https://…`.

**В пути формата `![…](…)` нельзя использовать пробелы**: `![](Scosglen 1.png)` не распознается как картинка и останется текстом. Замените пробелы на `%20` — `![](Scosglen%201.png)` — или используйте `![[Scosglen 1.png]]`, в нём пробелы допустимы.

Добавить файл в ассеты пресета можно в редакторе: кнопкой «Изображение…», через Ctrl+V из буфера обмена или перетаскиванием файла в поле текста. Ссылка на него вставится сама.

### Размер

Размер задаётся в подписи после `|`:

| Разметка | Размер |
|---|---|
| `![иконка\|32](icon.png)` | ширина 32, высота по пропорциям |
| `![иконка\|32x24](icon.png)` | вписать в 32 × 24 |
| `![иконка\|x24](icon.png)` | высота 24, ширина по пропорциям |
| `![иконка](icon.png)` | исходный размер, но не шире оверлея |

Внутри таблицы `|` нужно экранировать: `![иконка\|32](icon.png)`. Иначе Markdown посчитает его границей ячейки.

Картинки стоят в строке вместе с текстом, поэтому их удобно ставить как иконки рядом с названиями: `![skill|24](skill.png) Название`.

## Настройки вкладки

Блок кода с языком `focus-overlay` меняет вид оверлея, пока открыта эта вкладка. На оверлее сам блок не показывается.

````markdown
```focus-overlay
corner: bottom-right
width: 520
height: 700
scale: 1.2
font-size: 15
opacity: 50%
text-color: #FFFFFF
accent-color: #3498DB
```
````

Блок меняет только окно с содержимым вкладки. Полоса с названиями вкладок от этого блока не зависит: у неё свои настройки (окно «Настройки» → «Полоса вкладок»), поэтому при переключении вкладок она не прыгает. Если содержимое и полоса вкладок стоят в одном углу, отступ содержимого считается от полосы: оно не залезает на неё, даже если `offset-y` меньше её высоты, а высота уменьшается на величину сдвига. Если `offset-y` и так больше, он сохраняется. В другом углу содержимое стоит ровно по своим `offset-x` и `offset-y`.

Неуказанные параметры берутся из настроек пресета (`system.md`) и общих настроек, см. [порядок применения](#порядок-применения-настроек). Блок можно поставить в любом месте вкладки. Строки `# …` и `// …` считаются комментариями. Вместо `:` можно писать `=`.

| Параметр | Значение |
|---|---|
| `corner` | угол экрана: `top-left`, `top-right`, `bottom-left`, `bottom-right`, или центр верхнего/нижнего края: `top-center`, `bottom-center` (для них `offset-x` не учитывается) |
| `offset-x`, `offset-y` | отступ от края экрана в пикселях |
| `width`, `height` | размер оверлея в пикселях (минимум 150 × 100) |
| `scale` | **множитель** к масштабу из предыдущих уровней: `1.2` — на 20 % крупнее. Горячие клавиши масштаба продолжают работать |
| `font-size` | размер шрифта (6–48) |
| `opacity` | прозрачность фона: `0.5` или `50%` |
| `text-color`, `accent-color` | цвет: `#RRGGBB`, `#AARRGGBB` или имя (`White`, `Gold`) |

Названия параметров не зависят от регистра, дефисов и подчёркиваний: `font-size`, `fontSize` и `font_size` значат одно и то же.

### Настройки пресета: system.md

Файл `system.md` в корне папки пресета задаёт вид для всех его вкладок. Он не показывается как вкладка. В нём учитываются только блоки ```` ```focus-overlay ```` с теми же параметрами, что и во вкладках; любой другой текст игнорируется, а редактор и импорт предупреждают о нём.

````markdown
```focus-overlay
corner: bottom-center
width: 600
```
````

В редакторе `system.md` открывается кнопкой «⚙ system.md — настройки пресета» над списком вкладок. При экспорте пресета он сохраняется в архив, при импорте папки или архива — подхватывается из корня.

### Порядок применения настроек

Каждый следующий уровень переопределяет указанные в нём параметры предыдущего:

1. **Настройки приложения** — окно «Настройки» → «Оверлей».
2. **Настройки пресета** — `system.md`.
3. **Настройки вкладки** — блок `focus-overlay` во вкладке.
4. **Изменения с клавиш** — масштаб (`Ctrl+Alt+=` / `-`) и положение (`Ctrl+Alt+Z` вверх, `B` вниз, `X` влево, `C` по центру, `V` вправо). Действуют на все вкладки и пресеты и сохраняются после перезапуска. Сброс — `Ctrl+Alt+R` или пункт «Сбросить положение и масштаб» в меню трея.

`scale` на уровнях 2–4 — множитель: итоговый масштаб = масштаб приложения × `scale` пресета × `scale` вкладки × масштаб с клавиш.

Клавиши положения меняют только одну ось: `Ctrl+Alt+Z` поднимает оверлей наверх, оставляя его слева, по центру или справа, а `Ctrl+Alt+X` сдвигает влево, не меняя верх/низ. Прикреплённая полоса вкладок за ними не двигается — её угол берётся только из настроек приложения.

## Ошибки разметки

Focus Overlay проверяет вкладки и сообщает о проблемах:

- изображение не найдено (битая ссылка) или файл не является изображением;
- пробелы в пути картинки формата `![…](…)`;
- ошибки в блоке `focus-overlay`: неизвестный параметр, неверное значение, строка не в формате `параметр: значение`.

После импорта пресета (из файла или папки) появляется окно со списком ошибок по вкладкам. В редакторе ошибки текущей вкладки показываются красным списком под текстом и обновляются по мере ввода; двойной клик по ошибке выделяет её строку.
